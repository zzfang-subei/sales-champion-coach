# 实战演练场景库 v1.0 - 全行业版

## 第一部分：客户类型模拟库

### 1. 理性分析型客户

#### 人设特征
- **基础特征**：重数据、要证明、算投资回报
- **说话风格**：逻辑清晰、用词精准、喜欢问"为什么"
- **决策特点**：慢而稳、要对比、重证据

#### 模拟对话示例
```
客户："你说能提升30%效率，有数据支撑吗？"
客户："ROI多久能达到正向？"
客户："和竞品相比，优势在哪里？"
客户："能看看其他客户的实际效果吗？"
```

#### 应对策略
- 用数据说话
- 提供详细方案
- 展示成功案例
- 逻辑推导清晰

#### 各行业表现
- **B2B**：要求看产品演示、技术白皮书
- **保险**：计算保费收益比、对比条款
- **教育**：了解课程大纲、师资背景
- **房产**：分析投资回报、地段潜力

---

### 2. 情感驱动型客户

#### 人设特征
- **基础特征**：重感觉、看关系、凭直觉
- **说话风格**：感性表达、故事多、说"我感觉"
- **决策特点**：快但易变、重视信任、要认同感

#### 模拟对话示例
```
客户："我感觉你们挺专业的"
客户："主要是要合得来，做生意先做朋友"
客户："这个给我的感觉不错"
客户："你们的服务态度我很认可"
```

#### 应对策略
- 建立情感连接
- 分享成功故事
- 展现真诚关怀
- 营造良好氛围

#### 各行业表现
- **B2B**：重视长期合作关系、团队氛围
- **保险**：在乎代理人的关心、服务态度
- **教育**：看老师是否用心、有爱心
- **房产**：喜欢销售顾问的真诚、不强势

---

### 3. 犹豫不决型客户

#### 人设特征
- **基础特征**：怕做错、总担心、要完美
- **说话风格**："我再考虑"、"不着急"、"等等看"
- **决策特点**：拖延、反复、需要推动

#### 模拟对话示例
```
客户："我要再想想"
客户："现在时机不太合适"
客户："等我们内部商量一下"
客户："下个月再说吧"
```

#### 应对策略
- 帮助梳理思路
- 消除具体顾虑
- 创造决策动力
- 提供安全保障

#### 各行业表现
- **B2B**：担心实施风险、怕影响现有业务
- **保险**：纠结保额和保费、怕买错
- **教育**：担心效果、怕浪费时间金钱
- **房产**：怕买贵、怕贬值、怕位置不好

---

### 4. 价格敏感型客户

#### 人设特征
- **基础特征**：精打细算、对比价格、要优惠
- **说话风格**："太贵了"、"有折扣吗"、"最低多少"
- **决策特点**：价格第一、忽视价值、爱砍价

#### 模拟对话示例
```
客户："太贵了，便宜点"
客户："别人家只要一半价格"
客户："能不能再优惠点？"
客户："这个价格超预算了"
```

#### 应对策略
- 价值重塑
- 成本分析
- 分期方案
- 增值服务

#### 各行业表现
- **B2B**：压缩预算、要求降价、威胁换供应商
- **保险**：只看保费不看保障、总说太贵
- **教育**：对比多家价格、要求试听优惠
- **房产**：不停砍价、要求送车位装修

---

### 5. 怀疑防备型客户

#### 人设特征
- **基础特征**：不信任、怕被骗、要验证
- **说话风格**："真的吗"、"忽悠人吧"、"哪有这么好"
- **决策特点**：验证多、决策慢、随时退出

#### 模拟对话示例
```
客户："你们是不是骗子？"
客户："天下哪有免费的午餐"
客户："说得太好了，不真实"
客户："我被骗过，不会再上当"
```

#### 应对策略
- 提供证明材料
- 客户见证背书
- 小步骤验证
- 透明化沟通

#### 各行业表现
- **B2B**：要求试用、查公司背景、找推荐人
- **保险**：怀疑理赔、不信收益、查保险公司
- **教育**：质疑师资、怀疑效果、要看资质
- **房产**：查五证、验产权、怀疑承诺

---

### 6. 冲动购买型客户

#### 人设特征
- **基础特征**：决策快、易激动、凭感觉
- **说话风格**："就要这个"、"现在就买"、"别说了"
- **决策特点**：快速决定、容易后悔、要即时满足

#### 模拟对话示例
```
客户："行，就这个了！"
客户："别介绍了，怎么付款？"
客户："现在就能用吗？"
客户："赶紧的，我急着要"
```

#### 应对策略
- 快速响应
- 简化流程
- 立即交付
- 预防后悔

#### 各行业表现
- **B2B**：看演示就决定、不细看合同
- **保险**：听完就买、不研究条款
- **教育**：试听就报名、一次买多课
- **房产**：看房就定、不议价

---

### 7. 专业挑剔型客户

#### 人设特征
- **基础特征**：很懂行、爱挑刺、显专业
- **说话风格**：术语多、纠细节、找毛病
- **决策特点**：标准高、对比多、难满足

#### 模拟对话示例
```
客户："你们的技术架构是什么？"
客户："这个功能实现原理不对"
客户："我用过5家，都有问题"
客户："细节处理不够专业"
```

#### 应对策略
- 展示专业度
- 承认不足
- 技术对话
- 定制方案

#### 各行业表现
- **B2B**：深究技术细节、挑战方案、测试极限
- **保险**：研究条款、计算IRR、对比精算
- **教育**：考察教学法、质疑课程设计
- **房产**：看建筑质量、研究规划、挑户型毛病

---

### 8. 关系导向型客户

#### 人设特征
- **基础特征**：重关系、讲人情、要面子
- **说话风格**："看在咱们关系"、"给个面子"、"都是朋友"
- **决策特点**：关系好就买、要特殊待遇

#### 模拟对话示例
```
客户："咱们都这么熟了，优惠多点"
客户："你帮我，我也会帮你"
客户："朋友介绍的，应该靠谱"
客户："以后多合作，互相照顾"
```

#### 应对策略
- 维护关系
- 给足面子
- 特殊待遇
- 长期互惠

---

### 9. 完美主义型客户

#### 人设特征
- **基础特征**：追求完美、注重细节、标准极高
- **说话风格**："这里不够好"、"还能更好吗"、"我想要最好的"
- **决策特点**：反复修改、永不满足、追求极致

#### 模拟对话示例
```
客户："这个细节能调整吗？"
客户："有没有更好的方案？"
客户："我要的是完美，不是差不多"
客户："每个细节都要到位"
```

#### 应对策略
- 耐心打磨
- 持续优化
- 定制服务
- 承诺改进

---

### 10. 从众跟风型客户

#### 人设特征
- **基础特征**：没主见、随大流、要安全感
- **说话风格**："别人都买什么"、"哪个卖得好"、"大家都选哪个"
- **决策特点**：跟随主流、害怕特殊、要群体认同

#### 模拟对话示例
```
客户："其他人都选什么？"
客户："这个是主流吗？"
客户："有多少人在用？"
客户："是不是大家都这么做？"
```

#### 应对策略
- 展示销量
- 客户案例
- 市场趋势
- 从众心理

## 第二部分：行业场景模拟库

### A. B2B销售场景

#### 场景1：首次拜访
**背景设定**：第一次拜访潜在客户公司
**客户角色**：部门经理/采购经理
**关键挑战**：建立信任、了解需求

**模拟对话流程**：
1. 开场寒暄（1-2分钟）
2. 公司介绍（3-5分钟）
3. 需求了解（10-15分钟）
4. 初步方案（5-10分钟）
5. 下一步约定（2-3分钟）

#### 场景2：方案演示
**背景设定**：向决策团队演示解决方案
**客户角色**：技术、业务、财务多方
**关键挑战**：满足不同角色诉求

#### 场景3：招投标现场
**背景设定**：正式投标演讲
**客户角色**：评标委员会
**关键挑战**：在限定时间内打动评委

#### 场景4：合同谈判
**背景设定**：最终商务谈判
**客户角色**：采购总监/法务
**关键挑战**：价格、条款、交付的博弈

#### 场景5：售后续约
**背景设定**：合同到期续约谈判
**客户角色**：已合作客户
**关键挑战**：提价、增值、竞争对手

---

**客户角色**：基本认可但还在犹豫

**客户角色**：焦虑的出险客户
**关键挑战**：安抚情绪、高效理赔、深化信任

## 第三部分：难度进阶设计

### 初级难度（1-3级）
**客户特点**：
- 需求明确
- 预算充足
- 态度友好
- 容易沟通

**挑战要素**：
- 基础问答
- 简单异议
- 常规流程
- 标准话术

**成功标准**：
- 完成基础流程
- 回答常见问题
- 保持专业礼貌
- 达成简单成交

---

### 中级难度（4-6级）
**客户特点**：
- 需求模糊
- 预算有限
- 半信半疑
- 有所防备

**挑战要素**：
- 深度挖需
- 价值塑造
- 异议处理
- 竞品对比

**成功标准**：
- 准确把握需求
- 有效处理异议
- 建立基本信任
- 促成有效进展

---

### 高级难度（7-9级）
**客户特点**：
- 需求复杂
- 决策谨慎
- 专业挑剔
- 多方比较

**挑战要素**：
- 复杂决策链
- 激烈竞争
- 价格压力
- 技术挑战

**成功标准**：
- 影响关键人
- 战胜竞争对手
- 获得价格认可
- 达成复杂成交

---

### 专家难度（10级）
**客户特点**：
- 极度理性
- 经验丰富
- 要求苛刻
- 随时测试

**挑战要素**：
- 所有困难叠加
- 突发状况处理
- 极限压力测试
- 综合能力考验

**成功标准**：
- 游刃有余
- 超出预期
- 获得认可
- 完美成交

---

## 第五部分：反馈话术库

### 鼓励性反馈
```
"非常好！你的开场很自然，客户明显放松了戒备。"
"这个问题问得很到位，直击客户的核心需求！"
"处理异议的思路很清晰，客户的疑虑明显减少了。"
"把握成交时机很准，客户已经准备好了！"
"整体表现非常专业，有销冠的潜质！"
```

### 建设性反馈
```
"开场稍显生硬，试试先从客户感兴趣的话题入手。"
"这里可以多问一个为什么，深挖背后的真实需求。"
"讲产品时间太长了，记住要讲客户的利益而不是功能。"
"客户说贵的时候，不要急着降价，先塑造价值。"
"成交信号已经出现了，要果断一些，不要错过时机。"
```

### 改进建议
```
"下次遇到这种情况，你可以这样说：[具体话术]"
"建议使用SPIN提问法，会让挖需求更有层次。"
"试试FAB陈述法，让客户更容易理解价值。"
"可以用认同隔离法处理这个异议，效果会更好。"
"记住：客户要的不是便宜，而是占便宜的感觉。"
```
